# ربط دقة مع Moodle

## المرحلة الأولى: تصدير العلامات (جاهزة)
- من صفحة «نتائج الامتحان» زر **تصدير لـ Moodle**.
- مرة وحدة لكل مجموعة: المعلم ينزّل قائمة طلاب الكورس من Moodle (العلامات ← تصدير ← ملف نصي، أو المشاركون ← تنزيل) ويرفعها في دقة. دقة تربط كل طالب بحسابه بالاسم (والمعلم يصحّح غير المربوط يدوياً).
  - يُحفظ لكل طالب معرّف واحد فقط: البريد أو اسم المستخدم أو رقم الهوية (`students.moodle_identifier[_kind]`).
- بعدها: تنزيل ملف CSV فيه عمودان (المعرّف، العلامة) للأوراق **المعتمدة فقط**، ورفعه في Moodle: العلامات ← استيراد ← ملف CSV.
- الكود: `src/lib/moodle.ts` و`src/components/groupB/MoodleExportDialog.tsx`.

## المرحلة الثانية: الربط الكامل LTI 1.3 (لم تُبنَ بعد)
- مسؤول Moodle يضيف دقة كأداة خارجية مرة واحدة.
- المعلم يضيف نشاط «دقة» داخل الكورس (Deep Linking)، الطالب يفتحه ويرفع ورقته بدون رمز.
- سحب الطلاب من الكورس (NRPS) وإرجاع العلامة بعد اعتماد المعلم (AGS).
