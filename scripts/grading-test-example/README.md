# مجلد تجربة الدقة

1. انسخ هذا المجلد إلى `grading-test/` في جذر المشروع (هذا الاسم مستبعد من Git لأن فيه أوراق طلاب).
2. عدّل `exam.json`: الأسئلة، الإجابة النموذجية، ومعايير التصحيح بالعلامات.
3. ضع صور الأوراق في `grading-test/papers/`:
   - صورة واحدة لكل ورقة، مثل `paper01.jpg`، أو
   - مجلد لكل ورقة فيه صورة لكل صفحة، مثل `paper02/1.jpg` و`paper02/2.jpg`.
4. اكتب تصحيحك أنت في `teacher-scores.csv`: سطر لكل ورقة، وعمود لكل سؤال (رقم السؤال في العنوان).
5. ضع مفتاح Claude في ملف `.env.local` في جذر المشروع: `ANTHROPIC_API_KEY=...`
6. شغّل: `npx tsx scripts/grading-accuracy.ts grading-test`

النتيجة تُحفظ في `grading-test/results.md` (ملخص) و`results.csv` (تفاصيل كل سؤال).
تجربة 20 ورقة على النماذج الثلاثة تكلّف تقريباً أقل من دولار ونصف.
